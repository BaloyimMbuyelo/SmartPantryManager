# Smart Pantry Manager

Smart Pantry Manager is an Android application designed to help users manage pantry ingredients, quantities, units, and expiry dates.

## Features

- View pantry ingredients
- Add ingredients
- Record ingredient quantities
- Record measurement units
- Record expiry dates
- Store ingredient information using a local database

## Technologies

- Java
- Android Studio
- Android SDK
- SQLite
- Gradle

## Project

This project is being developed as part of an academic Android application project.
